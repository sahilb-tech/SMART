## Source fidelity note

The lesson summaries and topic mappings are adapted from the supplied textbooks. The visual concept guide is an instructional aid made from the lesson's concept labels and captions; it is not a claim that every printed textbook illustration has been extracted. The original PDF is linked from each lesson so teachers can consult the exact printed page artwork and diagrams.
